The question

How can several agents participate in the same conversation without silently flattening a user’s context, source attribution, or each model’s identity?

What I built

I built a React, TypeScript, and Firebase application for concurrent multi-user and multi-agent sessions. The system combines live state, authentication, configurable agent experiences, sandboxed playgrounds, and three memory namespaces: shared user context plus separate model-specific spaces with source-aware retrieval.

The hard part

The central design problem is not only prompting. It is deciding where information belongs, who can read it, and how a user can understand why an agent appears to know something.

What remains

This is a deployed application, not a claim of enterprise security. Public materials will be reviewed against the current BYOK and security boundaries before a deeper architecture diagram is published.
