The question

How can a personal operating system connect project history, health/status signals, and attention support without turning automation into a brittle or punitive layer?

What I built

Ledger spans desktop, web, and mobile-oriented surfaces with authenticated state and realtime synchronization. Bulwork adds a local service and browser extension that can allow, block, or ask about distracting destinations; it also supports plans, focus sessions, and learned decisions without placing provider secrets in the extension.

The hard part

The enforcement policy treats an incorrect block as more costly than an incorrect allow. That produces an explicit “ask” path and fail-open behavior when confidence is insufficient—a small product decision with large consequences for trust.

Evidence to add

This case study will later show the system diagram and a short walkthrough of a safe “Ask” decision. A full authenticated desktop/service/extension stack will not be embedded into GitHub Pages.
