The question

Exploratory analysis becomes hard to trust when comparison views drift apart, assumptions stay hidden, or results cannot be exported and revisited.

What I built

I built a Next/React interface with a FastAPI data service for uploads, PCA coordinates, clustering, tiled comparison views, annotations, workspace persistence, and exportable artifacts. The tool supports multiple datasets while guarding against invalid row/key alignment before transferring fields across views.

The hard part

The useful unit is not a single beautiful 3D plot; it is a repeatable comparison workflow. Workspace state, alignment checks, and export are part of the analysis surface.

What remains

The full upload/workspace experience requires a separately hosted API. A later public version will use synthetic/prepared data or a deployed backend; this page will not present the current local FastAPI app as a GitHub Pages demo.
