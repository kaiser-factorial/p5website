The question

Exploratory research data needs quick, inspectable views—but survey data is often sensitive, and a visual tool should not require researchers to upload it just to find structure.

What I built

Scatter Lab profiles a dropped CSV, XLSX, or Parquet file immediately, then lets a researcher assign numeric columns to 2D/3D scatter axes and color. It supports optional PCA projection from supplied loadings, DBSCAN and deterministic k-means++ clustering, and per-cluster composition breakdowns normalized by either cluster or group.

The workflow

Up to four views can be pinned into a tiled comparison grid. Columns such as cluster labels can transfer between datasets by row order or key match, with alignment checks before a transfer can silently mis-join respondents. Sessions persist locally in IndexedDB and can be shared as a workspace file; exports include PNG, client-encoded rotating GIF, and a self-contained interactive HTML view.

The engineering decision

The first version paired a Next.js interface with a FastAPI, pandas, and scikit-learn backend. I migrated parsing, imputation, standardization, PCA projection, DBSCAN, and k-means into TypeScript and removed the backend entirely. The result is a static, push-to-deploy tool where research data never leaves the researcher’s machine.
