The question

What changes when an AI companion’s primary output is not another chat window, but a physical and expressive presence?

What I built

I integrated an ESP32-S3 audio device with wake/audio behavior, RGB response language, and a hosted-agent path with memory/transcript components. The project crosses board bring-up, device interaction, cloud/service integration, and an interaction design in which color and sound are part of the response rather than a status afterthought.

Evidence to add

This will become a video-first project page with a short physical demo and a device-to-agent architecture diagram.

Validation boundary

The public page will distinguish board/audio stages that have been physically verified from end-to-end hosted speech and transcript paths that still need confirmation. It will not expose a public device-control endpoint or private service credentials.
